Contempo Dance Academy

A personal web development practice project created to improve my skills in designing and developing responsive webpages.

About the Project

Contempo Dance Academy is a sample dance academy webpage designed for learning and practicing frontend web development. It is not an official commercial website.

The webpage includes sections such as:

- Home
- About
- Dance Classes
- Instructors
- Contact
- Registration

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Responsive webpage design
- Navigation menu
- Attractive user interface
- Dance class information
- Instructor information
- Contact section
- Registration form

Purpose

This project was created for educational and practice purposes to improve my knowledge of HTML, CSS, JavaScript, webpage design, and frontend development.

Project Status

Completed as a personal learning project.
